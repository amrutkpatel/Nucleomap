# NucleoDesk
NucleoDesk (formerly NucleoMap) Public Beta is a Windows desktop application for sequence analysis, plasmid visualization, cloning design, primer planning, restriction digest analysis, and chromatogram review

# NucleoDesk

[![DOI](https://zenodo.org)](https://doi.org)

A comprehensive desktop DNA design workspace built with React, TypeScript, Vite, and Tauri for molecular biology workflows.
